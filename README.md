#### 📌 ex1: การประกาศตัวแปรและชนิดข้อมูล (Variables & Data Types)

* **การทำงาน:** ทดลองใช้ `let` และ `const` ในการประกาศตัวแปรแทนการใช้ `var` เพื่อจัดการ Scope ของข้อมูลให้ปลอดภัย
* **แนวคิดหลัก:** ใช้ `const` สำหรับค่าที่ไม่ต้องการให้เปลี่ยนแปลง (เช่น ค่าคงที่) และใช้ `let` สำหรับตัวแปรที่มีการอัปเดตค่าภายหลัง พร้อมศึกษาสตรักเจอร์ของชนิดข้อมูลประเภท String, Number, Boolean, Array และ Object



#### 📌 ex2: ตัวดำเนินการและการเปรียบเทียบ (Operators & Expressions)

* **การทำงาน:** ใช้ตัวดำเนินการทางคณิตศาสตร์ ตรรกศาสตร์ และการเปรียบเทียบค่า
* **แนวคิดหลัก:** ใช้ Strict Equality (`===` และ `!==`) ในการเปรียบเทียบข้อมูลเสมอ เพื่อตรวจสอบทั้ง **ค่า (Value)** และ **ชนิดข้อมูล (Type)** เพื่อป้องกันข้อผิดพลาดจากการแปลงชนิดข้อมูลอัตโนมัติ (Type Coercion)



#### 📌 ex3: การควบคุมทิศทางโปรแกรม (Control Flow with `if...else`)

* **การทำงาน:** เขียนเงื่อนไขการตัดสินใจของโปรแกรมตามโจทย์กำหนด
* **แนวคิดหลัก:** โครงสร้างคำสั่งใช้ `if`, `else if`, และ `else` โดยมีการใส่ปีกกา `{ }` ครอบบล็อกคำสั่งทุกครั้งแม้จะมีคำสั่งเดียว เพื่อความเป็นระเบียบและลดโอกาสเกิด Bugs ในโค้ด



#### 📌 ex4: ระบบตัดเกรดและตรวจรับข้อมูล (Grade Evaluation & Data Validation)

* **การทำงาน:** สร้างฟังก์ชัน `toGrade(score)` รับค่าคะแนน $0-100$ เพื่อแปลงเป็นเกรดตามช่วงคะแนนที่กำหนด
* **แนวคิดหลัก:**
1. ทำ **Data Validation** ตรวจสอบว่าคะแนนอยู่ในช่วง $0-100$ หรือไม่ก่อนทำการตัดเกรด หากข้อมูลไม่ถูกต้องจะปฏิเสธทันที
2. เรียงเงื่อนไข `if / else if` จาก **คะแนนมากไปน้อย** ($80 \rightarrow 75 \rightarrow 70 \dots$) เพื่อให้การเช็กเงื่อนไข `>=` ทำงานได้อย่างถูกต้อง
3. ใช้ลูป `for...of` วนทดสอบข้อมูลใน Array ครบทั้ง 13 กรณี



#### 📌 ex5: ระบบคิดราคาอาหารด้วย `switch` (Switch Statement & Fall-through)

* **การทำงาน:** คำนวณราคารวมของรายการอาหารตามเมนู ขนาด และจำนวน
* **แนวคิดหลัก:**
1. ใช้ **Fall-through Pattern** รวม `case` ของเมนูที่มีราคาเท่ากัน ($50$ บาท) ได้แก่ ข้าวผัด, ข้าวมันไก่, และข้าวหมูแดง ไว้ด้วยกันเพื่อลดการเขียนโค้ดซ้ำซ้อน
2. ใส่ `default` เพื่อรองรับกรณีที่ผู้ใช้สั่งเมนูหรือขนาดที่ไม่มีในรายการ
3. คำนวณราคารวมด้วยสูตร: $\text{ราคาเมนู} \times \text{ตัวคูณขนาด} \times \text{จำนวน}$



#### 📌 ex6: ระบบตรวจสอบสิทธิ์เข้าใช้งาน (Authentication & Pipeline Flow)

* **การทำงาน:** สร้างฟังก์ชัน `login()` ตรวจสอบสิทธิ์และเงื่อนไขการเข้าใช้งานระบบเป็นลำดับขั้น
* **แนวคิดหลัก:**
1. **Authentication First:** ตรวจสอบ Username และ Password เป็นลำดับแรก เพื่อยึดหลักความปลอดภัย (Security) และป้องกันการรั่วไหลของข้อมูลระบบ (Information Disclosure) ให้แก่ผู้ที่ยังไม่ได้ยืนยันตัวตน
2. เรียงลำดับการตรวจสอบอย่างเป็นขั้นตอน: Username/Password $\rightarrow$ สถานะบัญชี (`isActive`) $\rightarrow$ อายุ (`age`) $\rightarrow$ สิทธิ์ผู้ใช้งาน (`role`)
3. ออกแบบฟังก์ชันให้เป็น **Pure Function** โดยใช้การ `return` ค่าข้อความผลลัพธ์ออกมา แล้วค่อยนำมาแสดงผลด้วย `console.log` ด้านนอกตามหลักการเขียนโค้ดที่ดี
